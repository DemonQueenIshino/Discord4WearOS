# Discord4WearOS

A native Discord client tailored for Wear OS smartwatches (built with Kotlin and Jetpack Compose for Wear OS).

> **Disclaimer**: Third-party Discord clients violate Discord's Terms of Service. Use at your own risk.

### Features
- **Authentication**: Discord Remote Auth (QR Code scanning) and local web server for easy token entry on LAN.
- **Messaging**: Real-time gateway events, direct messages, server channels, threads, and replies.
- **Media**: Avatars, custom server emojis, stickers, image attachments, voice message playback.
- **Wear OS Native**: Material 3 for Wear OS (`wear.compose.material3`), rotary scrolling, and round display optimizations.

### Getting Started in Android Studio
1. Clone this repository:
   ```bash
   git clone https://github.com/DemonQueenIshino/Discord4WearOS.git
   ```
2. Open the project folder in Android Studio.
3. Select your Wear OS device or emulator.
4. Press **Run ▶**.
